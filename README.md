# The Hollywood SIGN

**SIGN = Shoot days, Income, Grosses, News.** Film-industry data on an illustrated studio lot, drawn in code
without generative AI imagery. Crowds, lights, and other details reflect public measurements of employment,
production, viewing, and trade coverage. Select a signal to see its figure and source.

Live: **https://laurenneal.github.io/hollywood-sign/**

This repository is the published site only: the scene, the data it reads, and the source tables. It is
regenerated by a scheduled job every two hours (data) and on every change to the scene; the history is one
commit deep on purpose. The feeds, tests, and documentation live in a separate private repository.
Its future source-code release is undecided.

The `evidence/` pages publish dated analyses with frozen observations, exact source locations,
comparison links, and attributed downloads. Feed updates do not silently rewrite an evidence edition.

- [SOURCES.md](SOURCES.md): every signal, its source, series id, cadence, licence, and the evidence quote.
- [LICENSES.md](LICENSES.md): licence terms for everything under `data/`. The compilation is CC BY-SA 4.0.
- [method.json](method.json): the SIGN index's components, weights, scale, and changelog. The `method` column of
  the `data/history/sign_index*.csv` files says which version computed each row (empty before versions were
  recorded).
- [LICENSE](LICENSE): the scene code is MIT.
- `data/signals.json`: the contract the scene reads; `data/history/*.csv`: every value with its vintage.
